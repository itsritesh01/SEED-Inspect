# SEED Inspect

SEED Inspect is a student prototype for fictional engineering site inspections.
It is not a company system, and it does not approve real site work.

## What you need

- Windows
- Python
- The project folder `C:\my code\seed_inspect`
- The virtual environment already used in this project

## Start the website

Open PowerShell in the project folder. The prompt must start with `(venv)`.

If the tables have never been created, run this once:

```powershell
python init_db.py
